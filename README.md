# SPOT public releases

Latest published version: v0.28.9.

Complete editable Python sources, tests and documentation are included in each signed source ZIP under Releases. SPOT code is MIT licensed; third-party notices remain in the source package.

Devices download over HTTPS without login or tokens. They must verify Ed25519 signatures using their previously trusted installation key. SHA256SUMS alone is not an authenticity proof.

The automatic GitHub source archives contain this channel README; download the explicitly named spot-MAJOR.MINOR.PATCH.zip asset for SPOT.
